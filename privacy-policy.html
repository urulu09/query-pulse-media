Privacy Policy — Query Pulse Bot

Last updated: 2026-10-17

Query Pulse Bot is a personal automation tool used solely by its owner to publish original, AI-assisted educational video content (about SQL and DevOps topics) to the owner's own social media accounts, including YouTube (Query Pulse, Query Pulse ES) and TikTok (@query.pulse).

Google / YouTube data we access

The app uses the YouTube Data API and YouTube Analytics API, authenticated via Google OAuth, solely to manage the owner's own YouTube channels. Specifically it uses these scopes:

  • youtube.upload — to upload the owner's own videos to the owner's own channel.
  • youtube — to add the owner's own uploaded videos to the owner's own playlists, and to post comments from the owner's own channel on the owner's own videos.
  • youtube.readonly — to read the owner's own channel and video metadata (e.g. to avoid duplicate topics).
  • yt-analytics.readonly — to read performance statistics (views, retention, likes, comments) for the owner's own videos, used only to inform future content topics.

The app does not access, collect, store, or share any data belonging to other Google/YouTube users, viewers, or third parties. It never reads email, contacts, Drive, or any other Google data outside the YouTube scopes listed above.

TikTok data we access

The app uses TikTok's Content Posting API only to upload video content to the owner's own TikTok account. It does not access, collect, store, or share any data belonging to other TikTok users.

Data we store

The app stores only what is required to operate: OAuth access/refresh tokens for the owner's own accounts (used solely to authenticate API requests) and a log of previously published video topics and basic performance statistics (to avoid duplicate content and inform future topics). No user-identifiable data beyond the owner's own accounts is retained.

Data sharing

No data is sold, shared, or disclosed to any third party. Data is used exclusively to operate this single-user automation for its owner.
